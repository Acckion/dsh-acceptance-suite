# 第一次运行测试

视频演示验收材料；不改变任何既有故意状态。

## 必需环境

Node.js 24+、Git。已有测试仅使用标准库，不需要安装依赖。

## 命令与结果含义

- 仓库根 `npm test`：运行 ts-monorepo 现有测试，是主分支绿基线。
- 仓库根 `npm run test:node-app`：运行 add 故意缺陷的红基线；不能把它写成通过。
- Python 可选：根目录 `npm run test:python`；需要相应 Python 工具链。
- Rust 可选：根目录 `npm run test:rust`；需要 Cargo 与 Rust。
